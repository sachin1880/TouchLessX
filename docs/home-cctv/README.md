# TouchlessSecurity

The integration of **TouchlessX** (touchless desktop control) and **HomeSmartCCTV**
(old Android phone as a home security camera) into one touchless smart security
platform.

This is a separate project. The original repositories are not changed by work here:

| Folder | Copied from | Original |
|---|---|---|
| `touchlessx/` | TouchlessX at commit `e58b31f` | https://github.com/sachin1880/TouchLessX |
| `homesmartcctv/` | HomeSmartCCTV at commit `31778fd` | https://github.com/sachin1880/HomeSmartCCTV |

If anything here goes wrong, delete this folder; the originals are untouched.

Status: integration in progress — see `docs/INTEGRATION_PLAN.md`.
